# Responsive Landing Page — Freelance Web Dev Services

A responsive landing page built as part of the **CodeOrbit Tech Web Development Internship**, promoting freelance web development services.

## 🔗 Live Site
Not hosted yet — open `index.html` locally, or host free via [GitHub Pages](https://pages.github.com/).

## 📌 About
A single-page site pitching small-scale freelance web development work — landing pages, portfolios, responsive design, and small fixes. Built as a design/layout exercise using CSS Grid and Flexbox.

## ✨ Features
- Fully responsive layout (mobile, tablet, desktop)
- Sticky header with mobile hamburger navigation
- Hero, Services (CSS Grid cards), Why Me, and CTA/Contact sections
- Working "Email Me" call-to-action
- Smooth scroll navigation with scroll-margin offset for the sticky header
- Accessible: visible keyboard focus states, respects reduced-motion preferences

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, Grid, media queries, custom properties)
- JavaScript (mobile nav toggle, dynamic footer year)
